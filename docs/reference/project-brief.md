## How to use it

Treat the shared conversation as source material. Convert its stable conclusions into focused pages in this wiki so readers do not need to reconstruct decisions from a chat transcript.

For each decision or requirement, record:

| Field | What to capture |
| --- | --- |
| Topic | A short, searchable name |
| Decision | What was agreed |
| Rationale | Why this choice was made |
| Evidence | Data, links, or constraints that support it |
| Owner | Who is responsible for the next action |
| Status | Proposed, accepted, in progress, or complete |
| Source | A link to the brief or a more specific source |

!!! info "Traceability"
    Add a source link near the claim it supports. A reader should be able to tell which details came from the project brief and which were added later.
