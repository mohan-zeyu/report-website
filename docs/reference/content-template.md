# Content template

Copy the source below when creating a new report or decision page.

```markdown
# Page title

One paragraph explaining what this page covers and why it matters.

## Summary

- Main conclusion
- Main supporting fact
- Recommended action

## Context

Describe the problem, audience, scope, and constraints.

## Evidence

Present the data, observations, or sources behind the conclusion.

| Measure | Value | Source |
| --- | ---: | --- |
| Example | 0 | [Project brief](https://chatgpt.com/share/6aab766a-b104-83ec-b3d3-c22c2887cf3c) |

## Recommendation

State the action, owner, and expected result.

## Open questions

- [ ] Question that still needs an answer

## Sources

- [Project brief](https://chatgpt.com/share/6aab766a-b104-83ec-b3d3-c22c2887cf3c)
```

## File naming

Use lowercase words separated by hyphens:

```text
good: quarterly-performance.md
good: survey-methodology.md
avoid: Quarterly Performance FINAL v2.md
```
